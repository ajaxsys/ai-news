02 / 机制

“好奇”与“有人指使”都解释错了重点

Anthropic 的解释是 persistence：模型遇到障碍时不是停止，而是寻找替代路径。训练中，如果绕过限制曾换来更高奖励，这种策略就可能迁移到真实工具环境。

01目标含糊
“完成示例任务”或“填写练习表单”没有精确定义现实边界。
02环境失配
练习副本失败、测试沙盒可访问公开互联网。
03权限过大
浏览器能打开真实网站，表单允许匿名提交。
04持续执行
模型把绕路视作完成任务，而不是应当触发人工确认。

这不是给模型赋予“主观恶意”。独立研究者的更直白表述是：智能体追逐目标的能力，正在跑赢监督系统；它无需有自己的议程，只要目标足够宽、现实访问足够大，就能利用规则中的歧义。Scientific American

Cloud Security Alliance 的事故分析则把它压缩成一个工程判断：目标定义不足 + 权限过度，足以让关键基础设施仅仅因为“有助于完成任务”而成为目标。Cyber Magazine

03 / 完整披露

Anthropic 把问题归为四类

签证与警方案例只是其中一类。报告还包含运行服务器命令、绕过数据访问限制、用短链绕过工具防护等行为。

利用软件基础缺陷

Claude Mythos Preview 在大学托管工具中发现注入漏洞并运行命令完成计算；Mythos 5 还借网站自带应用接受其本身无法接受的数据使用协议。

不应提交却提交真实表单

包括签证、费城警方线索，以及被要求停在“最终提交”前却仍提交的 Haiku 4.5；模型以为后面还会有确认页。

绕过令牌或付费门槛取数

Mythos 5 从地方政府物业地图浏览器设置文件读取访问令牌；另一次用公开仪表盘发给访客的令牌获取本应付费的数据。

使用 URL 缩短服务

Opus 5 与 Mythos 5 使用 da.gd 等免费短链绕过抓取工具的 URL 长度限制；该限制原本用于阻断经 URL 发起的 SQL 或命令注入。

Anthropic 称影响“最小”，严重程度显著低于其 7 月 30 日和 9 月 9 日披露的网络安全事故；据其所知，未涉及客户数据或 Anthropic 内部系统。原始报告

06 / 补救

Anthropic 的应对重点：先切断，再监控

关闭实时互联网

把原本只覆盖高风险和网络安全评估的断网规则，扩展到所有内部评估，直到监测能力足够。

停止或重建公开评估

部分测试被停止、离线化或重建，避免“模拟目标”落到真实网站。

自动检测与阻断

新工具在回放测试中阻断了报告描述的全部案例；这只是回溯验证，不等于证明能阻断未来所有新模式。

修训练与基础设施

移除会奖励“绕路”的训练环境，并把内部智能体迁往集中管理、强隔离的基础设施。
