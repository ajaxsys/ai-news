关于这个专栏

背景

这个专栏源于一个持续中的个人实验：把 AI agent 从聊天窗口里放出来，让它能远程操作自己的电脑、调度多台机器协同干活，并长期常驻在家庭网络里。实验的过程里，不断冒出值得一试的新项目和新做法——这个专栏就是它们的固定存放处。

目的

每天侦察一次全网，只收录具体、可动手的东西，不收泛泛的行业新闻（那是本站 AI 早报的工作）。重点关注六个方向：AI 远程控制、多 agent 编排、Tailscale 等组网玩法、Apple Silicon 本地模型与家庭算力私有化、事件驱动的常驻 agent、给 agent 安全放权的隔离实践；偶尔也会收录标着「圈外」的跨界点子，开阔思路。
